# 열려 있던 부채 두 건 재측정 (2026-08-07)

인수인계 §6 의 부채 표에서 두 항목을 재봤다. **둘 다 적혀 있던 사유가 틀렸다.**
하나는 할 일이 아니었고, 하나는 폐기해도 되는 근거가 없었다.

---

## 1. `SEC legacy_no_document 1,478` — **재수집은 답이 아니다**

부채 표는 *"재수집이 답이라고 문서에 적고 아무것도 안 함"* 으로 적었다.
아무것도 안 한 것은 맞고, **재수집이 답이라는 것이 틀렸다.**

### 먼저 수부터 다르다

```
provenance='legacy_no_document' 전체        2,971
  그중 귀속됨                                1,505
  그중 미귀속 (부채가 가리키던 것)            1,466   ← 2026-08-06 측정 당시 1,478
```

1,478 은 전체가 아니라 **그날의 미귀속 수**였다. 그 사이 policy_event 12건이 붙어
1,466 이 됐다. 유형별로는:

| event_type | 전체 | 귀속 | 미귀속 |
| --- | ---: | ---: | ---: |
| insider_trade | 1,004 | 573 | **431** |
| analyst | 882 | 882 | **0** |
| policy_event | 623 | 12 | **611** |
| sec_8k | 462 | 38 | **424** |

`analyst` 882 는 전건 귀속됐다. 부채 표가 "SEC" 로 묶은 것도 정확하지 않았다 —
미귀속의 절반 이상이 SEC 문서가 아니다.

### 855 건은 문서가 없어서 못 붙는 게 아니다

원 문서(`findings-2026-08-06`)는 `sec_8k` + `insider_trade` 855 건을
*"SEC EDGAR 에서 8-K·Form 4 를 CIK 와 함께 다시 받아야 한다"* 로 결론지었다.
**그 전제를 재봤다.**

`insider_trade` 요약은 **첫 토큰이 티커**다. 재수집 없이 읽힌다:

```
ELV 내부자 Boudreaux Gail P - PURCHASE +$1,002,230
JEF 내부자 Sumitomo Mitsui Financial Group, Inc. P - PURCHASE +$318,717,006
GRML · STDN · LGHL · PFBX · PDI · ENR ...
```

그래서 물어야 할 것은 "문서가 있느냐" 가 아니라 **"그 티커가 우리 유니버스에
있느냐"** 다. 실측:

```
미귀속 insider_trade                431
  첫 토큰이 티커 모양                431   (100%)
  그 티커가 core.entity Stock 에 있음   0   ← 0건
```

`sec_8k` 도 같다. 요약은 `SEC 8-K Exodus Movement, Inc. (2026-07-17)` 처럼
회사명을 그대로 들고 있다:

```
미귀속 sec_8k                        424
  유니버스 기업명을 언급한 것            0   ← 0건
```

> **855건 전부가 우리가 커버하지 않는 기업에 대한 것이다.** SEC EDGAR 에서 다시
> 받아도 **한 건도 귀속되지 않는다** — 우리에게 없는 종목의 문서를 받아올 뿐이다.
> 이것은 지난 세션이 유니버스 확장(E)에서 이미 잰 것과 같은 모양이다:
> *"93.8% 가 미귀속인 것은 필터가 맞게 도는 것이지 결함이 아니었다."*

### 남은 611 — policy_event 는 붙을 곳이 여전히 없다

```
미귀속 policy_event                            611
  시장 어휘(analytics.market_topic_term)에 걸림    35   (trade 33 · market 2)
  어휘에 하나도 안 걸림                          576
```

걸리는 35 조차 갈 곳이 없다. `trade` 와 `market` 주제에는 **매핑된 계열이 하나도
없다**(계열이 있는 주제는 rates · growth · inflation · fx · energy 다섯뿐).

### 결론

**이 항목은 "할 일" 이 아니라 "재분류" 다.** 재수집으로는 0건이 풀린다.
실제로 무언가 하려면 둘 중 하나여야 하고, 둘 다 별개의 결정이다:

- **855** → 유니버스를 넓히는 문제. 지난 세션이 잰 13배 비용 항목(E)이고
  *"무엇을 보고 싶은가"* 가 선행한다
- **611** → `trade`·`market` 주제에 계열을 붙이거나, 어휘가 못 잡는 576건을
  **테마**로 잇는 문제 (→ §2)

## 2. `analytics.theme 534행 폐기 예정` — **폐기해도 되는 근거가 없다**

### 534 는 한 표가 아니다

```
analytics.theme              138
analytics.theme_membership   396
                             ─────
                             534
```

### 대체품이 존재하지 않는다

폐기 분류의 근거는 *"v2 가 `theme_exposure_snapshot` 으로 대체 설계"* 였다.
실측:

```
analytics 스키마의 theme 관련 표    theme, theme_membership   ← 둘뿐
theme_exposure_snapshot            없음 (표도 마이그레이션도 없음)
유일한 언급  docs/plan/insight-platform-backend-db-v2/00-backend-db-master-plan.md:279
```

**계획서에 축 이름이 적혀 있을 뿐이다.** "대체품이 있으니 버려도 된다" 가 아니라
**"대체품은 계획서에만 있고 원본은 아무도 안 읽는다"** 였다. 둘은 전혀 다른 상태이고,
앞의 것으로 적어두면 다음 사람이 안심하고 넘어간다.

### 그리고 지금 값이 있을 수 있다

§1 에서 잰 것과 맞물린다. 미귀속 `policy_event` 611 중 **576 이 시장 어휘에 하나도
안 걸린다.** 어휘가 못 잡는 사건을 종목에 잇는 경로로 `database-ownership.md` 가
지목한 것이 정확히 이 두 표다:

> *"테마 두 테이블이 가장 값어치가 크다. 사건을 테마로 분류하는 코드만 붙이면,
> 기업 이름이 본문에 없는 시장 뉴스도 테마를 거쳐 종목에 닿는다."*

`theme_membership` 396행은 종목 198개를 덮고 `rationale_relation_ids` 로 근거까지
들고 있다.

### 한 것

`run-table-reachability-audit.ts` 의 수용 사유를 **사실로 고쳤다.** 표는 여전히
읽히지 않으므로 목록에는 남지만, 사유가 없는 표를 가리키고 있었다.

```
전  '138행 — 폐기 예정. v2 가 theme_exposure_snapshot 으로 대체'
후  '138행 — 미사용. 대체 설계(theme_exposure_snapshot)는 표가 없다'
```

**폐기하려면 `theme_exposure_snapshot` 을 실제로 만들거나, 폐기를 별도로 결정해야
한다.** 이 세션은 어느 쪽도 하지 않았다 — 전자는 v2 설계 작업이고 후자는
사용자 판단이다.

## 3. 이 두 건에서 하지 않은 것과 이유

| 안 한 것 | 이유 |
| --- | --- |
| SEC EDGAR 8-K/Form 4 재수집기 | **0건 귀속된다.** 측정으로 답이 아님이 확인됐다 |
| 유니버스 확장 | 지난 세션이 13배 비용으로 잰 항목. "무엇을 보고 싶은가" 가 선행 |
| `trade`·`market` 주제에 계열 매핑 | `market` 후보는 KOSPI 인데 그건 시장 팩터 교체와 얽힌 모델링 결정이다 (→ `ecos-collector-2026-08-07.md` §5) |
| 사건→테마 분류기 | 576건을 살릴 수 있는 유일한 경로지만 새 기능이다. 재분류만 하고 만들지 않았다 |
| `theme_exposure_snapshot` 생성 | v2 설계 작업. 계획서에 축만 있고 스키마가 없다 |
| `analytics.theme` 폐기 | 근거가 없어졌으므로 폐기하지 않았다 |
