# 근거 인스펙터 오버레이·리사이즈·모달 전환 설계

## 목표

오늘 화면의 근거 인스펙터가 열릴 때 기존 콘텐츠의 폭, 카드 배치, 스크롤 위치에 영향을 주지 않도록 한다. 데스크톱에서는 우측 드로어를 기본 표시 방식으로 사용하고, 사용자가 너비를 조절하거나 중앙의 넓은 모달로 전환할 수 있게 한다.

모바일은 현재의 하단 모달 동작을 유지한다. 백엔드, DB, 근거 데이터 계약은 변경하지 않는다.

## 확인된 문제

현재 데스크톱 인스펙터는 `WorkspaceShell`의 세 번째 그리드 열로 렌더링된다. 인스펙터가 열리면 셸이 `사이드바 + 콘텐츠 + 400px 인스펙터` 구조로 바뀌면서 기존 콘텐츠가 압축된다.

938px 뷰포트에서는 핵심 카드 뉴스 패널이 약 414px까지 줄어들어 카드와 근거 메타데이터가 비정상적으로 접힌다. 인스펙터에 높은 `z-index`만 지정해도 그리드 열은 그대로 남기 때문에 이 문제는 해결되지 않는다. 인스펙터를 문서 흐름에서 분리해야 한다.

## 접근 방식 비교

### 1. 포털 기반 고정 오버레이 — 채택

인스펙터를 포털로 렌더링하고 화면 우측에 `position: fixed`로 배치한다.

- 기존 콘텐츠 레이아웃이 변하지 않는다.
- 사이드바, 상단 바, 카드 위에 안정적인 레이어를 만들 수 있다.
- 중앙 모달 전환과 포커스 관리가 기존 `Dialog` 경계 안에서 가능하다.
- 드로어와 모달이 동일한 상세 콘텐츠를 공유한다.

### 2. 셸 내부의 고정 오버레이

현재 DOM 위치는 유지하면서 인스펙터만 `position: fixed`로 바꾼다.

- 변경량은 작지만 상위 요소의 stacking context와 overflow에 영향을 받기 쉽다.
- 셸 구현과 인스펙터 배치가 계속 결합된다.
- 중앙 모달 전환 시 별도의 배치 예외가 늘어난다.

### 3. 조절 가능한 분할 화면

현재처럼 콘텐츠 옆에 인스펙터 열을 유지하고 경계를 드래그하게 한다.

- 두 영역을 동시에 비교하기는 쉽다.
- 인스펙터가 기존 콘텐츠를 밀지 않아야 한다는 요구와 충돌한다.
- 좁은 데스크톱에서 카드 레이아웃 붕괴가 계속 발생한다.

## 최종 표시 방식

### 기본 우측 드로어

- 데스크톱에서 상세 항목을 선택하면 우측 드로어로 연다.
- 드로어는 화면 우측 상단에 고정하고 높이는 `100dvh`로 한다.
- 기본 너비는 520px이다.
- 최소 너비는 420px, 최대 너비는 760px이다.
- 실제 최대 너비는 뷰포트 여유 공간을 넘지 않도록 제한한다.
- 기존 콘텐츠에는 너비 변경, 여백 추가, `transform`, 스크롤 이동을 적용하지 않는다.
- 드로어는 사이드바와 상단 바보다 높은 레이어에 표시한다.
- 밝은 중성 오버레이를 사용해 기존 콘텐츠의 구조는 읽히되 포인터와 포커스는 드로어 안에 둔다.
- 오버레이를 누르면 드로어만 닫히고, 뒤의 카드에는 같은 클릭이 전달되지 않는다.

### 너비 조절

- 드로어 왼쪽 가장자리에 12px 너비의 포인터 조작 영역을 둔다.
- 시각적 경계선은 1px로 유지하고 hover, focus, drag 상태에서만 강조한다.
- 왼쪽으로 끌면 넓어지고 오른쪽으로 끌면 좁아진다.
- 기존 `DataGrid`의 포인터 캡처와 `role="separator"` 접근성 패턴을 재사용한다.
- 키보드 `ArrowLeft`와 `ArrowRight`로 16px씩 조절한다.
- 조절 중 선택 영역이나 본문 텍스트가 드래그되지 않게 한다.
- 확정된 너비는 `sessionStorage`에 저장한다.
- 같은 브라우저 탭 세션과 워크스페이스 화면 이동에서는 유지하고, 새 브라우저 세션에서는 기본 520px로 복귀한다.
- 저장값이 현재 뷰포트 제한을 벗어나면 렌더링 시 안전 범위로 보정한다.

### 중앙 모달 전환

- 인스펙터 헤더에 `넓게 보기` 아이콘 버튼을 추가한다.
- 버튼을 누르면 동일한 상세 콘텐츠를 중앙의 넓은 모달로 전환한다.
- 중앙 모달 기본 너비는 760px이고 최대 960px까지 사용하되, 화면 좌우에 최소 24px 여백을 둔다.
- 중앙 모달에서는 배경 딤과 모달 포커스 잠금을 사용한다.
- 헤더의 `옆에서 보기` 버튼을 누르면 이전 우측 드로어 너비로 돌아간다.
- 표시 방식 전환은 상세 데이터를 다시 요청하지 않으며 현재 스크롤 가능한 상세 콘텐츠를 그대로 사용한다.
- 드로어 너비는 세션에 기억하지만 드로어/모달 표시 방식은 기억하지 않는다. 새 상세 항목은 항상 드로어로 시작한다.

### 모바일

- 767px 이하에서는 현재 하단 모달 표시를 유지한다.
- 모바일에는 드래그 너비 조절과 중앙 모달 전환 버튼을 노출하지 않는다.
- 배경 딤, 포커스 잠금, 닫기 후 선택 항목으로 포커스 복귀를 유지한다.

## 컴포넌트 경계

- `ResearchWorkspacePage`는 인스펙터 열림 상태, 선택 레코드, 닫기 후 포커스 복귀만 소유한다.
- `EvidenceInspector`는 `drawer | modal | mobile` 표시 상태와 전환 버튼을 소유한다.
- 드로어 너비 상태와 세션 저장은 인스펙터 전용 훅 또는 작은 내부 유틸리티로 격리한다.
- 공용 `Dialog`는 포털, 포커스, 오버레이 계약을 유지한다. 인스펙터에만 필요한 너비 상태를 공용 다이얼로그 API에 추가하지 않는다.
- 리사이즈 핸들은 인스펙터 전용 요소로 두되 기존 `DataGrid`의 검증된 포인터·키보드 패턴을 따른다.

## 상호작용과 오류 처리

- 드로어를 닫으면 기존처럼 URL의 선택 레코드를 제거하고 열었던 항목으로 포커스를 돌린다.
- 모달에서 닫아도 동일한 닫기 흐름을 사용한다.
- 드로어와 모달 전환 중 로딩, 오류, 준비 상태를 보존한다.
- `sessionStorage` 접근이 차단되거나 저장값이 잘못되어도 기본 너비로 계속 동작한다.
- `prefers-reduced-motion`에서는 드로어와 모달 전환 애니메이션을 사실상 제거한다.
- 새 애니메이션 런타임이나 리사이즈 의존성을 추가하지 않는다.

## 검증 기준

- 인스펙터를 열기 전후 오늘 화면의 주요 패널 너비와 x좌표가 변하지 않는다.
- 드로어가 사이드바, 상단 바, 카드보다 높은 레이어에 표시된다.
- 드로어와 중앙 모달의 오버레이 클릭은 상세만 닫고 뒤 콘텐츠를 활성화하지 않는다.
- 기본 너비가 520px이고 포인터 조절 범위가 420~760px 안에 머문다.
- 키보드 방향키로 너비를 조절할 수 있고 현재 값이 접근성 속성에 반영된다.
- 조절한 너비가 같은 세션에서 닫기, 다시 열기, 워크스페이스 화면 이동 후에도 유지된다.
- 중앙 모달로 전환했다가 드로어로 돌아오면 이전 드로어 너비가 복원된다.
- 표시 방식 전환으로 상세 데이터 요청이 추가 발생하지 않는다.
- 모바일은 기존 하단 모달, 배경 비활성화, 포커스 복귀 동작을 유지한다.
- 데스크톱, 모바일, reduced-motion Playwright 검증을 추가한다.
- 포맷, lint, typecheck, 테스트, build를 통과한다.

## 제외 범위

- 드로어 너비를 사용자 계정이나 DB에 저장하는 기능
- 드로어/모달 표시 방식의 영구 기억
- 여러 상세 패널을 동시에 여는 기능
- 드로어를 좌측이나 하단으로 이동하는 기능
- 백엔드, DB, API 응답 계약 변경
