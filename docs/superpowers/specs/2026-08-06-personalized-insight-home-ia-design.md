# Stock Insight 개인화 인사이트 홈·메뉴 개편

## 목표

Stock Insight를 기능 모음이 아니라 다음 질문에 답하는 개인 투자 리서치 앱으로 재구성한다.

> 오늘 시장에서 무엇이 달라졌고, 그 변화가 내 관심종목과 어떻게 연결되며, 무엇을 더 확인해야 하는가?

제품은 계속 읽기 전용이다. 주문, 매매 실행, 목표가, 매수·매도 지시는 제공하지 않는다.

## 제품 구조 결정

기존의 아홉 개 평면 메뉴는 데이터 종류와 기능 이름을 같은 수준에 나열한다. 이를 사용자의 리서치 흐름에 맞춘 네 개의 주 메뉴로 줄인다.

1. `오늘` — 시장 요약과 개인화된 오늘의 브리핑
2. `내 종목` — 관심종목·보유종목 변화와 종목별 근거
3. `시장 연결` — 세계 레이더, 시장 전반, 테마·관계 탐색
4. `복기` — 내 리서치와 판단 이력

첫 구현 묶음에서는 기존 주소와 데이터 계약을 유지한다. 주 메뉴는 대표 주소에 연결하고, 합쳐질 하위 화면은 대표 화면 안의 진입 링크 또는 후속 묶음에서 통합한다.

- `오늘` → `/workspace/today`
- `내 종목` → `/workspace/stocks`
- `시장 연결` → `/workspace/radar`
- `복기` → `/workspace/research`

`데이터 상태`는 주 메뉴에서 빼고 사용자/보조 메뉴의 `데이터 신뢰도` 링크로 이동한다. 데이터가 채워지지 않은 `크립토`는 주 메뉴에서 제외한다. 기존 `/workspace/crypto`, `/workspace/themes`, `/workspace/history`, `/workspace/market-topic-news`, `/workspace/status` 주소는 깨지지 않게 유지한다.

## 오늘 화면 정보 순서

첫 진입 화면은 아래 순서를 고정한다.

### 1. 오늘의 시장 요약

KOSPI, NASDAQ, 금처럼 하루의 배경을 빠르게 이해할 수 있는 지표를 가로 요약으로 보여준다.

- 이 묶음에서 실시간 시세 API나 DB를 추가하지 않는다.
- 현재 데이터가 없는 항목은 프론트엔드 샘플 데이터로 제공한다.
- 샘플 값에는 `샘플 데이터`와 기준 시각의 성격을 명확히 표시한다.
- 실제 시세인 것처럼 보이는 실시간 문구나 자동 갱신 표현은 쓰지 않는다.

### 2. 핵심 카드 뉴스

현재 개인화 피드 중 중요도가 높은 2~3개를 큰 카드로 보여준다.

- 제목, 한 줄 요약, 시장, 발행 시각을 기본 정보로 사용한다.
- `왜 나에게 보였는지`를 짧게 표시해 일반 뉴스 앱과 차별화한다.
- 카드를 선택하면 기존 근거 상세 패널을 연다.

### 3. 내 관심종목 큐레이터 뉴스

관심종목이나 보유종목에 직접 연결된 뉴스를 별도 구역으로 보여준다.

- 직접 연결 항목을 우선한다.
- 종목명 또는 연결 이유를 함께 표시한다.
- 데이터가 없으면 임의의 개인화 결과를 만들지 않고 관심종목 등록 또는 수집 대기 상태를 안내한다.

### 4. 나머지 리스트 뉴스

카드 뉴스와 큐레이터 뉴스에 포함되지 않은 항목을 밀도 높은 목록으로 제공한다.

- 기존 분류 탭과 다음 페이지 불러오기를 유지한다.
- 같은 뉴스가 카드, 큐레이터, 목록에 중복 노출되지 않게 화면에서 제외 집합을 계산한다.
- 전체 피드가 비었을 때는 기존 빈 상태를 유지한다.

### 5. 시장 연결 경로와 확인할 리스크

오늘 뉴스가 내 관심종목이나 테마에 이어지는 이유를 화면 마지막에 요약한다.

- 현재 제공되는 관계 경로, 연결 출처, 신뢰도 정보를 재사용한다.
- `영향을 줄 수 있는 뉴스`, `확인할 리스크`, `테마와 연결된 기업`처럼 정보 제공형 문구를 쓴다.
- 관계 데이터가 없으면 분석을 꾸며내지 않고 아직 연결 경로가 없음을 표시한다.

## 화면 구성 원칙

- 상단에서 하단으로 `시장 배경 → 핵심 변화 → 내 종목 연결 → 전체 탐색 → 근거 확인`의 한 방향 흐름을 만든다.
- 카드 수를 제한하고, 나머지는 구조화된 행과 목록으로 표현한다.
- 데스크톱, 축소 사이드바, 모바일 시트에서 네 개의 주 메뉴 순서와 명칭을 동일하게 유지한다.
- 기존 상세 패널, 키보드 탐색, 포커스 복귀, 로딩·오류·부분·오래됨 상태를 보존한다.
- 새 애니메이션 런타임이나 UI 라이브러리는 추가하지 않는다.

## 데이터와 백엔드 경계

이번 묶음은 프론트엔드 정보 구조 개편이다.

- 기존 `WorkspaceToday`, 피드 분류, 관심종목 수, 관계 수, 출처 커버리지, 근거 상세 데이터를 그대로 사용한다.
- DB 스키마, 마이그레이션, 수집 작업, API 응답 계약을 변경하지 않는다.
- 시장 요약 샘플만 별도의 프론트엔드 상수로 격리해 이후 실제 API 데이터로 교체하기 쉽게 만든다.
- 개인화 데이터가 없거나 수집 중인 경우에는 명시적인 빈 상태를 보여준다.

## 검증 기준

- 사이드바와 모바일 메뉴에는 네 개의 주 메뉴만 우선 노출된다.
- 오늘 화면이 정한 1~5 순서로 렌더링된다.
- 샘플 시장 지표가 실제 데이터로 오인되지 않는다.
- 카드, 큐레이터, 일반 목록 사이에 동일 레코드가 중복되지 않는다.
- 피드 항목 선택과 근거 상세 패널, 분류 전환, 페이지 추가 로딩이 기존처럼 동작한다.
- 빈 데이터, 부분 데이터, 로딩, 오류 상태에서 화면 구조가 무너지지 않는다.
- 데스크톱과 모바일에서 가로 넘침이 없고 키보드·스크린리더 의미가 유지된다.
- 포맷, lint, typecheck, 테스트, build와 관련 Playwright 검증을 통과한다.

## 제외 범위

- DB 조작, 스키마 마이그레이션, 새 수집기 또는 외부 시세 API 연결
- 주문, 증권사 연동, 매수·매도 추천
- 크립토 데이터 생성 또는 빈 크립토 화면의 내용 채우기
- 모든 기존 하위 화면을 한 번에 재설계하는 작업
- 기존 주소 제거 또는 강제 리다이렉트
