# Today 상세 인스펙터·선택 상태 폴리시 설계

## 목표

Today 화면에서 뉴스 상세를 여닫고 전환하는 흐름을 더 빠르고 명확하게 만든다. 드로어와 모달은 모두 밝은 오버레이 위에 열리고, 바깥 영역을 누르면 뒤 콘텐츠를 활성화하지 않고 상세만 닫혀야 한다.

카드 뉴스, 리스트 뉴스, 시장 연결 경로의 선택 표현은 하나의 시각 언어로 통일한다. 현재의 상단 또는 좌측 컬러바는 제거하고, 은은한 배경·전체 보더·절제된 깊이감으로 선택 상태를 보여준다. 백엔드, DB, API 및 상세 데이터 계약은 변경하지 않는다.

## 현재 문제

- 데스크톱 드로어의 바깥 클릭·포인터 차단 계약이 명확하지 않아 뒤 카드가 함께 활성화될 수 있다.
- 드로어와 중앙 모달의 진입 스프링이 길게 잔동작해 빠른 뉴스 탐색 흐름을 방해한다.
- 카드 뉴스는 상단 컬러바, 리스트 뉴스는 좌측 컬러바를 사용해 같은 선택 상태가 다르게 보인다.
- 전환 버튼과 닫기 버튼이 비슷한 크기의 정사각형 아이콘 버튼이라 기능 구분이 약하다.
- 중앙 모달 오버레이가 너무 어두워 배경 문맥이 과하게 사라진다.

## 접근 방식 비교

### 1. Today 인스펙터에 한정한 동작·시각 폴리시 — 채택

인스펙터에 전용 모션과 오버레이 강도를 전달하고, Today 카드·리스트 선택 스타일만 통일한다.

- 다른 공용 다이얼로그의 모션과 오버레이를 바꾸지 않는다.
- 현재 포털, 포커스, URL 선택 상태 계약을 유지할 수 있다.
- 변경 범위와 회귀 위험이 가장 작다.

### 2. 공용 Dialog 기본값 전체 변경

모든 모달과 드로어의 스프링과 오버레이를 한꺼번에 조정한다.

- 제품 전체의 통일감은 생기지만 인증, 관리, 경고 다이얼로그까지 영향을 받는다.
- 이번 Today 폴리시 요구보다 범위가 크다.

### 3. CSS 선택자만 덮어쓰기

위치별 CSS로 속도와 선택 표현만 바꾼다.

- 변경량은 작지만 바깥 클릭, 포커스, 표시 방식 전환 같은 동작 계약을 명확히 다루지 못한다.
- 공용 모션 소유 경계를 우회하게 된다.

## 상호작용 설계

### 바깥 클릭 닫기

- 중앙 모달과 데스크톱 드로어는 모두 밝은 오버레이를 누르면 닫힌다.
- 오버레이는 뒤의 뉴스 카드와 리스트 행을 포인터·포커스 대상으로 만들지 않는다.
- 뒤 카드 위치를 누른 경우에도 현재 상세만 닫히고 선택 레코드는 바뀌지 않는다.
- 닫기 버튼과 `Escape` 동작, URL의 선택 레코드 제거, 닫은 뒤 포커스 복귀 계약은 유지한다.

### 빠른 모션

- Today 인스펙터에만 빠른 전환 프리셋을 적용한다.
- 진입은 약 180~220ms 안에 시각적으로 안정되는 높은 강성·충분한 감쇠의 스프링 또는 동등한 짧은 전환을 사용한다.
- 종료는 현재처럼 짧게 유지하되 포인터 차단은 즉시 해제한다.
- 드로어는 우측에서 짧은 거리만 이동하고, 중앙 모달은 과도한 횡이동 없이 짧은 이동과 불투명도 변화로 나타난다.
- `prefers-reduced-motion`에서는 즉시 전환한다.

### 밝은 공통 오버레이

- Today 인스펙터의 드로어와 모달은 배경의 카드와 페이지 구조가 식별되는 밝은 중성 딤을 사용한다.
- 어두운 검정막 대신 캔버스 색과 중성 잉크를 낮은 비율로 혼합한다.
- 깊이 구분은 오버레이 암도보다 모달의 전체 보더와 그림자가 담당한다.
- 텍스트 대비와 모달 포커스 잠금은 유지한다.

## 선택 상태 설계

카드 뉴스, 리스트 뉴스, 시장 연결 경로는 동일한 선택 토큰 조합을 사용한다.

- 상단·좌측 수직 컬러바와 방향성 inset shadow를 제거한다.
- 기본 표면에 accent를 낮은 비율로 섞은 은은한 선택 배경을 사용한다.
- 전체 둘레에 1px 혼합색 보더를 사용한다.
- 보더는 원색 accent보다 중성 보더와 accent를 섞어 과도하게 튀지 않게 한다.
- 내부에는 매우 얕은 하이라이트, 외부에는 낮은 불투명도의 짧은 그림자를 사용한다.
- 리스트 행은 평상시에도 투명 1px 보더 공간을 확보해 선택 시 콘텐츠 위치가 움직이지 않게 한다.
- 목록 컨테이너는 선택 보더와 그림자가 잘리지 않을 만큼의 안쪽 여백을 확보하고 기존 행 구분선과 겹치지 않게 한다.
- hover는 선택 상태보다 약하게 유지하고, focus-visible은 선택 보더와 별도로 식별 가능해야 한다.

## 전환 버튼 설계

- 정사각형 `IconButton` 대신 아이콘과 짧은 텍스트를 함께 쓰는 36px 높이의 보조 액션 버튼을 사용한다.
- 드로어에서는 `넓게 보기`, 모달에서는 `옆에서 보기`를 표시한다.
- 버튼은 pill에 가까운 둥근 형태, 은은한 표면색, 얕은 그림자를 사용한다.
- 닫기 버튼은 기존 32px 정사각형 X 버튼을 유지한다.
- 형태, 너비, 라벨 차이로 표시 방식 전환과 닫기 기능을 즉시 구분한다.
- 모바일에서는 기존처럼 전환 버튼을 숨긴다.

## 컴포넌트 경계

- `EvidenceInspector`가 바깥 클릭 허용, 표시 방식 전환, 전용 모션·오버레이 변형을 선택한다.
- 공용 `Dialog`는 Today 인스펙터가 전용 전환과 오버레이 클래스를 전달할 수 있는 최소 API만 제공한다.
- 다른 Dialog 호출부는 기존 기본값을 그대로 사용한다.
- `TodayView`는 카드, 리스트, 시장 연결 경로에 같은 `aria-current` 계약을 제공하고, `feed-ledger.module.css`가 공통 선택 표현을 소유한다.
- 새 애니메이션 런타임이나 UI 의존성은 추가하지 않는다.

## 검증 기준

- 드로어와 중앙 모달 모두 바깥 영역 클릭으로 닫힌다.
- 바깥 영역의 카드 위치를 눌러도 현재 상세만 닫히고 뒤 항목은 활성화되지 않는다.
- 닫기, `Escape`, 포커스 복귀, URL 선택 상태가 기존 계약을 유지한다.
- 드로어와 모달의 진입이 기존보다 빠르게 안정되고 reduced-motion에서는 즉시 끝난다.
- 모달 오버레이가 밝아져 배경 구조가 식별되면서도 모달 포커스가 명확하다.
- 카드, 리스트, 시장 연결 경로 선택 상태에 방향성 컬러바가 없고, 동일한 배경·전체 보더·그림자 언어를 사용한다.
- 목록의 선택 보더와 그림자가 상하좌우에서 잘리지 않는다.
- 선택 전후 카드와 리스트 콘텐츠 위치와 크기가 변하지 않는다.
- 전환 버튼이 텍스트가 있는 보조 액션으로 보이고 X 닫기 버튼과 구분된다.
- 데스크톱과 모바일 Playwright, 정적 계약 테스트, 포맷, lint, typecheck, 테스트, build를 통과한다.

## 제외 범위

- 공용 Dialog 전체의 기본 모션과 오버레이 변경
- 뉴스 상세 데이터 재요청 구조 또는 API 변경
- 백엔드·DB·스키마 변경
- 선택 상태 색상을 사용자 설정으로 제공하는 기능
- 모바일 하단 모달의 구조 변경
